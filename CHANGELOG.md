# Что нового

Здесь записано, что меняется в каждой версии. Раздел версии автоматически попадает в описание релиза на GitHub.

## 1.0.0

Первая версия Karnize - свободного форка Kordon 1.2.2 (© Efimov Dev, GPL-3.0).

- **Раздельная маршрутизация.** Claude, ChatGPT, Codex и Perplexity проверяются по адресу, который видят их собственные серверы (Cloudflare `/cdn-cgi/trace`). Если часть сервисов проверки IP идёт мимо VPN и они называют разные адреса, программы больше не стоят на паузе бесконечно. Своим приложениям можно указать `route:`, выключить проверку - `route_check: false`.
- **Исправлено: мгновенная заморозка Claude при правке config.yaml.** Если редактор (или `Set-Content` в PowerShell) сначала очищал файл, Kordon успевал прочитать пустой config, применял настройки по умолчанию и замораживал Claude. Теперь изменения читаются, когда файл «устоялся», а пустой файл не применяется.
- **Исправлено: домашний IP мог разрешиться сам.** Текущий IP разрешается автоматически только при самом первом запуске, а не каждый раз, когда список «Разрешено» опустел.
- **Первый запуск и «Разрешить IP» учитывают маршрут до сервисов**, а не только большинство сервисов проверки.
- **IP больше не «скачет» между проверками**: после согласия нужного числа сервисов Karnize ещё полсекунды ждёт остальных.
- **Статистика без ложных заморозок**: заморозка без запущенных программ не считается, а в истории пишется понятно, без «(-)».
- **Windows: `karnize status > файл` и конвейеры работают, кириллица в консоли не ломается.**
- **`karnize status`** берёт сервисы проверки из config.yaml и показывает маршрут до каждого сервиса.
- **Сторож** после серии падений размораживает программы, а не оставляет их на паузе до перезагрузки.
- Своё название, логотип, папка настроек (`%APPDATA%\Karnize`, `~/.config/karnize`) и автозапуск: Karnize не конфликтует с установленным Kordon. Обновления приходят только из релизов Karnize.

# История Kordon до форка

## 1.2.2 - 03.11.2026

- **Лицензия теперь GPL-3.0** (была MIT). Код по-прежнему открыт, но изменённые версии тоже обязаны оставаться открытыми. Название и логотип Kordon в лицензию не входят. Версии до 1.2.1 остаются под MIT.
- В «О программе» появилась кнопка «Написать в Telegram» (@efimov_dev).
- Панель: когда приложения заморожены, заголовок короткий («Приложения заморожены»), а причина и отсчёт - строкой ниже.
- Панель: у каждого запущенного приложения свой статус - с правилами под приложение одно может работать, пока другое заморожено.
- Панель: подпись DNS без VPN теперь честная - «та же страна, что у IP» вместо «идёт через VPN».

## 1.2.1 - 03.11.2026

- **Исправлено: после обновления из меню на Mac Kordon мог не запуститься снова.** Старая версия закрывалась, а новая не стартовала: macOS считала, что Kordon ещё работает. Теперь новая версия запускается напрямую и дожидается, пока старая закроется.

> Если вы обновлялись из меню с 1.1.0 и значок Kordon пропал, просто откройте Kordon из «Программ» (или строкой установки). Начиная с 1.2.1 это не повторится: перезапуском управляет уже исправленная версия.

## 1.2.0 - 03.11.2026

**Панель Kordon, свои правила для приложений, доверенные сети, утечки DNS.**

- **Панель Kordon** - отдельное окно (пункт «Открыть панель Kordon…» в меню): обзор, приложения, разрешённые IP и страны, сети, статистика, история и все настройки переключателями. На Mac - окно приложения, на Windows - окно Edge без адресной строки, на Linux - вкладка браузера. Работает только на этом компьютере и только по секретному ключу из меню.
- **Свои правила для каждого приложения**: например, Claude только из NL, а Cursor из NL, DE и US. Каждая группа живёт своей жизнью: одно приложение заморожено, другое работает.
- **Доверенные сети**: дома или в офисе - без проверки IP, в остальных сетях защита как обычно. Сеть узнаётся по её роутеру, без доступа к геолокации. Пункт в меню «Доверять этой сети» и раздел «Сети» в панели.
- **Проверка утечки DNS**: если запросы к сайтам идут мимо VPN, Kordon предупредит (по умолчанию) или заморозит приложения (`dns_check: block`).
- **Статистика**: сколько раз отваливался VPN, сколько раз Kordon успел разморозить приложения, сколько закрыл, сколько времени они простояли - по дням за 90 дней, график за 14.
- **«Сообщить о проблеме»** в меню и панели: открывает заявку на GitHub с версией, системой и концом журнала, IP и MAC скрыты.
- Если у приложения убрали свои правила, оно размораживается с обычным уведомлением, а не молча.
- Кратковременная заморозка при запуске Kordon больше не попадает в статистику.

## 1.1.0 - 03.11.2026

**Обновления в один клик.**

- Раз в сутки Kordon проверяет, не вышла ли новая версия. Если вышла, придёт уведомление, а в самом верху меню появится «⬆ Обновить до …».
- По клику Kordon скачивает новую версию, сверяет её контрольную сумму с релизом, заменяет себя и перезапускается. Замороженные приложения на это время размораживаются, настройки остаются.
- Без клика ничего не ставится.
- Новая команда `kordon update` - то же самое из терминала.
- Проверку можно выключить: `update_check: false` в настройках.
- Галочка «Запускать при входе в систему» теперь показывает настоящее состояние, даже если автозапуск включили из терминала.
- Команды терминала больше не создают файл настроек раньше первого запуска (из-за этого не включался автозапуск).

> С 1.0.0 на 1.1.0 нужно обновиться вручную - строкой установки из README. Дальше обновления приходят сами.

## 1.0.0 - 03.11.2026

Первая версия.

- Замораживает выбранные приложения при смене сети, IP или пропаже интернета; размораживает, когда разрешённый IP вернулся; закрывает, если не вернулся за 20 секунд.
- Разрешённые IP, подсети и целые страны.
- Проверка IPv6: ловит VPN, которые заворачивают только IPv4.
- IP подтверждают минимум два независимых сервиса.
- Замораживается всё дерево процессов (MCP-серверы, `curl`, `git` внутри Claude Code).
- Реакция на системные события сети, а не только опрос.
- Надзиратель перезапускает Kordon, если тот упал.
- Готовые наборы: Claude, ChatGPT, Codex, Cursor, Windsurf, GitHub Copilot, Gemini CLI, Perplexity, Telegram, Discord, Slack, Zoom, плюс свои приложения.
- Значок в строке меню macOS и в трее Windows и Linux, история, пауза, режим для созвонов.
- Установка одной строкой с проверкой контрольной суммы, сборки подписаны аттестацией GitHub.
